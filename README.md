# Flashcards Cloud

A private multi-device flashcard web app.

## What is different from the local version?

- Same deck library on Mac, iPhone and iPad
- Email/password sign-in
- Generated decks saved in Supabase
- Uploaded PDFs are not saved
- Delete saved decks
- Full-screen study mode
- Click/Space = flip
- Left Arrow = previous card
- Right Arrow = next card
- Study navigation happens inside the browser for smooth switching
- Last card position is saved when you return to the Library

Start with `SETUP.md`.
